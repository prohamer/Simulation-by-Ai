歡迎來到 **Simulation-by-Ai**！本專案收錄了一系列結合 AI 輔助開發與網頁前端技術（HTML5、CSS3、JavaScript、Canvas 2D、Three.js 等）所打造的**單一檔案互動式教學模擬器**。

本計畫旨在將國中與高中的抽象科學概念（如：波動疊加、力矩平衡、熱傳導微觀模型、光學濾鏡、化學計量與基礎算術模型等）轉化為直觀、可操作的數位沙盒，讓學生能透過視覺化實驗進行探究學習。

## ✨ 專案特色

* **🚀 免安裝、跨平台**：所有模擬器皆以標準 Web 技術封裝，打開瀏覽器即可運行，完美相容課堂大屏、iPad、Chromebook 與個人電腦。
* **🎯 聚焦核心概念**：針對教學現場常見的迷思概念設計（例如：橫波與縱波密部/疏部對照、上皿天平騎碼歸零與讀數、水流與電流類比模型等）。
* **🛠️ 單一檔案架構**：多數教具採獨立 `.html` 結構設計，方便第一線教師直接下載單檔離線使用，或嵌入至 Google Classroom、學習吧等數位教學平台。
