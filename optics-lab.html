光學實驗台使用說明

畫面配置

  • 左側：章節與實驗選單，左上角按鈕可收合。
  • 中間：暗室實驗台，可切換 2D／3D；左邊是工具列，右上角是紙屏或屏幕上看到的影像。
  • 下方：引導任務，平常收合，點一下展開。
  • 右側：實驗控制、測量結果、觀察重點與情境快照；按「面板」可收合。平板直式使用時，面板會從右側滑出。

基本操作

想做的事操作方式
移動物體、光源、屏幕拖曳虛線圓圈。物體靠近 F、2F 時會自動對齊。
旋轉雷射、平行光、稜鏡點一下物體，拖曳藍色圓環旋轉（按住 Shift 每次轉 15°）；紅、綠箭頭只沿水平或垂直移動。
縮放與平移滾輪或雙指縮放，拖曳空白處平移；按「重設視角」回到原位。
3D 視角拖曳空白處旋轉，右鍵或 Shift＋拖曳平移。圓點與箭頭仍可拖曳，移動限制在實驗平面上。
紙屏影像視窗拖曳標題列移動，拖曳右下角調整大小，按「−」縮小。
調整數值使用右側面板的滑桿與按鈕，2D、3D 都能用。

工具列（實驗台左側）

  • 光源：自訂發光點、雷射、平行光源，點畫面放置，選取後可在右側調整光線數、寬度、顏色。
  • 光線開關：頂端／底部光線、三條特殊光線、成像、屏幕、觀察者眼睛。不適用的實驗會變灰色。
  • 繪圖：畫筆、手繪光線、量尺。畫好的線條可以點選、拖移，並在右側改顏色、粗細、虛線。
  • 復原、重做、快照：每一步都能復原；相機會把目前情境存到右側面板最下方。

情境快照

快照會保存實驗的所有設定、自訂光源、繪圖與視角。點縮圖就能回復；可以匯出成 JSON 檔分享，或把 JSON 檔拖曳到快照區匯入。快照也會暫存在這台裝置的瀏覽器中。

引導任務

每個實驗有 2～3 個任務，達成條件時會自動完成。預測題會暫時鎖住「成像」，作答後才揭曉；手繪光線題會檢查光線是否通過正確的點。完成紀錄只存在這台裝置的瀏覽器。

快捷鍵

Esc 回到選取工具、取消選取　Delete 刪除選取的光源或繪圖　Ctrl＋Z 復原　Ctrl＋Shift＋Z 或 Ctrl＋Y 重做

教學流程建議（每個實驗）

  1. 引起動機：用生活例子提問，例如「游泳池為什麼看起來比較淺？」「放大鏡為什麼能放大？」
  2. 先預測：開啟預測類任務，或用工具列關掉「成像」，請學生先用手繪光線作圖、預測像的位置。
  3. 動手實驗：學生拖曳物體、調整數值，記錄右側測量結果。
  4. 歸納規律：對照「觀察重點」整理結論。教師可事先存好關鍵情境的快照，上課時一鍵切換說明。
  5. 練習與評量：完成引導任務。手繪光線任務適合檢查作圖能力。

各節建議

單元建議順序重點活動
4-1 光的傳播（2 節）影子的形成 → 針孔成像比較點光源與有大小的光源；先預測針孔像的方向再揭曉；驗證「像高 ÷ 物高 ＝ 像距 ÷ 物距」。
4-2 反射（2 節）反射定律 → 平面鏡成像 → 凹面鏡與凸面鏡旋轉雷射量入射角與反射角、示範光路可逆與漫射；用量尺比較物距與像距；凹面鏡找焦點、凸面鏡看視野。
4-3 折射（1 節）光的折射 → 水中物體的位置開小車動畫解釋偏折方向；長方形磚觀察兩次折射；半圓形磚找臨界角與全反射；移動眼睛觀察視深。
4-4 透鏡（3 節）透鏡與平行光 → 透鏡成像 → 眼睛與視力矯正用平行光與量尺量焦距、切換三稜鏡組說明透鏡原理；三條特殊光線作圖；新增多個物體比較各位置的成像；用紙屏找實像；近視、遠視與矯正。
4-5 色散與顏色（2 節）三稜鏡色散 → 色光與物體的顏色觀察色散，用三個稜鏡重現牛頓合光；色光三原色混合；色紙在色光下與玻璃紙的顏色。

課堂使用小技巧

  • 投影時按全螢幕，再收合左右兩側，實驗台最大。
  • 分組使用平板時，直式畫面的實驗台較大；需要調整時再打開面板。
  • 教師可先準備好快照並匯出 JSON，傳給學生匯入，全班從同一個情境開始。
  • 每個實驗都有自己的網址（網址最後的 # 名稱），可以直接分享給學生。
