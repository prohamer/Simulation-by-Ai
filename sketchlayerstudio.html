✨ 如何同時「操作模擬」與「畫筆標註」？
嵌入後，畫面頂部會出現 「🎮 操作網頁/模擬 ⇄ ✏️ 在上方畫筆標註」 切換鈕：
• 切為 🎮 操作模式（或收合繪圖工具列）時，可直接拖動模擬器滑桿、點擊按鈕或控制 YouTube 影片，且已畫好的標註仍會浮在上方！
• 點選任一 ✏️ 繪圖工具（畫筆、箭頭、量尺等） 時，即可直接在模擬畫面正上方畫線標註。
⚠️ 注意：部分網站（如 GitHub 主站非 Pages 頁面）若有設定防嵌入保護（X-Frame-Options），請改用其 GitHub Pages (`*.github.io`) 網址。
